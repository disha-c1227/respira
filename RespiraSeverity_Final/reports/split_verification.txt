======================================================================
PREPROCESSING NOTES PER ARCHITECTURE
======================================================================

MobileNetV3-Small (EXISTING BASELINE — DO NOT RETRAIN):
  Input  : Grayscale(3) → Resize(224,224)
  Norm   : mean=[0.485,0.485,0.485]  std=[0.229,0.229,0.229]
  Note   : Grayscale repeated to 3 channels. Non-standard but consistent
           between training and inference. MUST NOT be changed.

EfficientNetB0 (NEW — Option B, architecture-native):
  Input  : Resize(256,256) → CenterCrop(224,224)
  Norm   : mean=[0.485,0.456,0.406]  std=[0.229,0.224,0.225]  (ImageNet RGB)
  Note   : Full RGB. X-rays will be loaded as RGB (3-channel grayscale).
           Augmentation: RandomHorizontalFlip, RandomRotation(10),
                         ColorJitter(brightness=0.1, contrast=0.1)

ResNet50 (NEW — Option B, architecture-native):
  Input  : Resize(256,256) → CenterCrop(224,224)
  Norm   : mean=[0.485,0.456,0.406]  std=[0.229,0.224,0.225]  (ImageNet RGB)
  Same augmentation strategy as EfficientNetB0.

DenseNet121 (NEW — Option B, architecture-native):
  Input  : Resize(256,256) → CenterCrop(224,224)
  Norm   : mean=[0.485,0.456,0.406]  std=[0.229,0.224,0.225]  (ImageNet RGB)
  Same augmentation strategy as EfficientNetB0.

LIMITATION TO DOCUMENT IN COMPARISON:
  MobileNetV3 uses grayscale-repeated normalisation; the three new models
  use standard ImageNet RGB normalisation. This means preprocessing differs
  between MobileNetV3 and the new trio. Architecture-to-architecture
  comparisons within the new trio (EfficientNetB0, ResNet50, DenseNet121)
  are on equal footing. Comparison against MobileNetV3 should note this
  preprocessing difference.
